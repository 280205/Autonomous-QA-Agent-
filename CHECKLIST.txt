PART A: DEPLOY BACKEND ON RAILWAY

STEP 1: CREATE RAILWAY ACCOUNT

□ Go to: https://railway.app/
□ Click "Login with GitHub"
□ Authorize Railway
□ Add credit card (required but free tier available)
   ⚠️ You get $5 free credit/month

STEP 2: CREATE NEW PROJECT

□ Click "New Project"
□ Select "Deploy from GitHub repo"
□ Choose: 280205/Autonomous-QA-Agent-
□ Click "Deploy Now"

STEP 3: CONFIGURE BACKEND

□ Click on your deployment
□ Go to "Settings" tab
□ Add these environment variables:
   
   Variable: OPENAI_API_KEY
   Value: sk-your-actual-key-here
   
   Variable: PORT
   Value: 8000

□ Go to "Settings" → "Networking"
□ Click "Generate Domain"
□ Copy the URL (e.g., https://autonomous-production.up.railway.app)

STEP 4: UPDATE START COMMAND

□ Go to "Settings" → "Deploy"
□ Set "Start Command":
   
   cd backend && python -m uvicorn main:app --host 0.0.0.0 --port $PORT

□ Save and redeploy

STEP 5: VERIFY BACKEND

□ Visit: [your-railway-url]/health
□ Should see: {"status":"healthy"}
□ ✅ Backend is live!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PART B: DEPLOY FRONTEND ON STREAMLIT

STEP 1: GO TO STREAMLIT CLOUD

□ Open: https://share.streamlit.io/
□ Click "New app"

STEP 2: CONFIGURE APP

□ Repository: 280205/Autonomous-QA-Agent-
□ Branch: master
□ Main file path: app.py
   ⚠️ Use app.py (NOT streamlit_app.py)

STEP 3: ADVANCED SETTINGS

□ Python version: 3.11
□ Secrets:

   OPENAI_API_KEY = "sk-your-key-here"
   BACKEND_URL = "https://your-railway-url.railway.app"

   ⚠️ Replace both values with actual ones!

STEP 4: DEPLOY

□ Click "Deploy!"
□ Wait 2-3 minutes
□ ✅ Frontend is live!
