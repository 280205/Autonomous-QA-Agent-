📋 STEP-BY-STEP DEPLOYMENT:

1️⃣  GO TO STREAMLIT CLOUD
    → https://share.streamlit.io/
    → Sign in with GitHub

2️⃣  CREATE NEW APP
    → Click "New app"
    → Repository: 280205/Autonomous-QA-Agent-
    → Branch: master
    → Main file: app.py

3️⃣  ADVANCED SETTINGS
    → Python version: 3.11
    → Add secrets (paste this):

    OPENAI_API_KEY = "sk-your-key-here"
    BACKEND_URL = "http://localhost:8000"

4️⃣  DEPLOY
    → Click "Deploy!"
    → Wait 3-5 minutes
    → Your app will be live!
